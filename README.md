# لينغوا — تعلّم لغة جديدة

صفحة هبوط ثنائية اللغة (العربية RTL والإنجليزية LTR) لتطبيق تعلّم لغات، مع درس مصغّر تفاعلي (6 أسئلة)، وتتبع سلسلة الأيام، وتبديل لغة محفوظ في localStorage.

## التشغيل
```bash
npm install
npm run dev
npm run build
```

## التقنية
React + TypeScript + Vite + Tailwind CSS، وأيقونات Phosphor.
